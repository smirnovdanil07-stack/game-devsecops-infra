# DevSecOps Infrastructure for Indie Game

Этот репозиторий содержит инфраструктурные решения (CI/CD, безопасность, автоматизация), которые я разработал для инди-игры моих друзей.

## Что здесь есть:
- **CI/CD:** GitHub Actions пайплайны для проверки кода.
- **Безопасность:** Сканирование C++ кода на уязвимости (Semgrep).
- **Скрипты:** Автоматизация рутины (Python/Bash).

## Мой стек:
Linux (Ubuntu Server), Docker, Git, GitHub Actions, Python.

## Статус:
В разработке. Код самой игры является собственностью команды и здесь не публикуется.
